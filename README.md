# hust-jobs · 华中科技大学就业网招聘信息汇总

自动抓取、聚合华中科技大学就业网的招聘信息，生成一个**单文件、可交互**的 HTML 汇总页面：宣讲会时间、投递截止时间一屏掌握，支持按日期筛选、星标收藏、打开时自动检查更新。

> 数据快照日期：2026-10-15 ｜ 适用届别：2027 届校招（秋招进行中）

## 功能特性

**两个信息专栏**
- **主表**（390 条）：写明了宣讲时间的招聘信息，卡片式展示，点击展开公告全文（微信外链正文已提取、图片已本地化）
- **未注明宣讲时间**（911 条）：就业网「招聘信息」栏目里没写具体宣讲时间的公告，与主表分开排版、字段一致，同样可展开可收藏

**两个日期分布图（点击柱子即筛选）**
- **宣讲会日期分布**：按宣讲日聚合；末列橙色「未注明时间」为独立筛选项，与具体日期互斥
- **简历投递截止日期分布**：按网申/投递截止日聚合；「招满即止」（黄色柱）与「未注明」（橙色柱）均为独立筛选项，与具体日期互斥；灰色柱表示已过截止日
- 四种筛选态（全部 / 具体日期 / 招满即止 / 未注明）全局互斥，柱子图与下拉框双向同步，再点一次当前柱子取消筛选

**简历投递截止时间核对（828/1301 条已注明）**
- 优先从就业网公告原文自动提取（275 条，附原句依据）
- 原文未写明的再联网核对企业官网 / 公开招聘平台（553 条，附来源链接与站点名）
- 「招满即止 / 尽快投递 / 长期有效」单独归类（34 条），不猜测、不编造日期；每条均可展开查看依据
- 页面底部区块四按截止日排序列出全部明细，可倒查来源

**公众号交叉核对**
- 以「华中科技大学就业指导与服务中心」公众号文章为补充信息源，核对/修订宣讲时间（补充缺失、修正过时，冲突以公众号为准），修订处带标记与依据

**我的关注**
- 星标收藏想去的宣讲会，展开即看；localStorage + 服务端双轨持久，换浏览器不丢失

**自动更新**
- `start.bat` 启动本地服务后，每次打开页面会自动检查源站最新信息并增量更新（抓新增详情、刷专栏、重跑核对、重建页面），也可手动点「检查更新」

## 目录结构

```
hust-jobs/
├── index.html            # 生成的汇总页面（自包含，可直接打开）
├── start.bat             # Windows 一键启动本地服务并打开页面
├── crawl.py              # 源站列表/详情抓取（urllib + 正则解析）
├── reparse.py            # 正文解析：div 栈配平、微信 js_content 提取、图片本地化
├── crawl_notime.py       # 「未注明宣讲时间」专栏抓取
├── crawl_wechat.py       # 公众号文章检索（搜狗微信搜索）与存档导入
├── revise.py             # 公众号核对修订（实体匹配 + 相似度）
├── deadline_local.py     # 公告原文提取投递截止时间（三套日期格式 +  plausibility 过滤）
├── merge_deadlines.py    # 合并本地提取 + 联网检索结果 → deadlines.json
├── split_todo.py         # 待联网清单分片（自动排除已覆盖条目）
├── build_html.py         # 生成 index.html（主表/专栏/分布图/收藏/修订标记）
├── update.py             # 增量更新流水线（一键串联以上所有步骤）
├── server.py             # 本地 HTTP 服务（静态托管 + 检查/刷新/收藏 API）
├── data/                 # 数据文件
│   ├── jobs.json         #   主表 390 条（含正文 HTML）
│   ├── jobs_notime.json  #   专栏 911 条
│   ├── deadlines.json    #   投递截止时间 828 条（794 具体日期 + 34 招满即止）
│   ├── deadlines_local.json / deadline_todo.json
│   ├── revisions.json    #   公众号核对修订记录
│   ├── wechat_articles.json
│   ├── favs.json / state.json
│   └── web/              #   历次联网检索原始结果（res_*.json，可追溯）
```

> 注：`images/`（微信文章本地化图片）与 `raw/`（源站 HTML 存档）均为可再生成的中间产物，已列入 `.gitignore`，不在本仓库中；克隆后重新运行抓取/解析脚本即可生成。

## 快速开始

**只看页面**：直接用浏览器打开 `index.html`（约 6.4 MB，自包含）。

**完整体验（推荐）**：双击 `start.bat`，自动启动本地服务并打开页面。此模式下：
- 打开页面自动检查源站更新（60 秒缓存，避免频繁请求）
- 「我的关注」跨浏览器持久（服务端 `data/favs.json`）
- 端口占用时自动顺延

**手动增量更新**：

```bash
python update.py            # 扫前 3 页，抓新增、刷专栏、重跑核对、重建页面
python update.py --full     # 全量比对（可识别已下线条目）
python update.py --check    # 只检查是否有更新，不写入
```

更新流水线内部顺序：抓列表 → 找新增 → 抓详情 → 刷专栏 → 公众号核对 → 保存 → 截止时间提取合并 → 重建页面。

**补跑联网截止时间核查**（针对仍未注明的条目）：

```bash
python split_todo.py 10 400   # 生成 10 个待查分片（自动排除已覆盖）
# 对每个 data/web/todo_*.json 逐家检索，结果写回 data/web/res_*.json
python merge_deadlines.py && python build_html.py
```

## 数据来源与判定口径

| 来源 | 说明 |
|---|---|
| 就业网公告原文 | 最权威；截止时间从正文/标题提取，附原句依据 |
| 企业官网 / 公众号 / 公开校招平台 | 原文未写明时才联网补充，附来源链接；往年届别信息不采信 |
| 「华中科技大学就业指导与服务中心」公众号 | 宣讲时间交叉核对，冲突以公众号为准 |

判定口径（宁缺毋滥，绝不编造）：
- 只认「简历投递 / 网申 / 报名 / 申请」截止；笔试、面试、宣讲会时间不算
- 只采信**企业官方渠道**明确写出的「招满即止 / 长期有效 / 尽快投递」；第三方平台的统一聚合标签不算
- 高校就业网平台的「职位有效期 / 到期时间」字段不等同网申截止，不采信
- 截止日期只接受 2026-09-01 至 2027-08-31 区间

## 技术说明

- 纯 Python 标准库实现（无第三方依赖）：`urllib` + `http.cookiejar` 抓取，正则解析，GBK/UTF-8 编码自动探测
- 微信文章正文用 div 栈配平提取 `js_content`，懒加载图片转本地并带 Referer 防盗链
- 搜狗微信搜索带 cookie 会话、跳转链接拼接解析、反爬退避
- 实体匹配：剥离「股份有限公司」等后缀、过滤「管理培训生」等泛词，difflib 相似度阈值 0.72，避免张冠李戴
- 增量判重：URL + 标题 + 时间双重判重；`state.json` 缓存带条目数一致性校验
